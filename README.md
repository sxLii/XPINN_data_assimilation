# XPINN_data_assimilation

This repository contains the original implementation of the XPINN framework for hydraulic transient modeling and data assimilation in water distribution systems.

**This repository is no longer actively maintained.** Future development and integration of physics-informed neural network frameworks are continued in the main project:

[TMF-PINN: Physics-Informed Neural Network Framework for Transient Mixed Flow](https://github.com/sxLii/TMF-PINN/tree/paper-version-xpinn)

The archived version of this repository is preserved for reference.
